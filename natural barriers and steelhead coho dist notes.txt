notes on accessing statewide steelhead and coho predictive distribution layers and natural barriers datasets:
Verified:
https://geodataservices.wdfw.wa.gov/arcgis/rest/services/ApplicationServices/FP_Sites/MapServer/5
 
Not Field Verified:
https://geodataservices.wdfw.wa.gov/arcgis/rest/services/ApplicationServices/FP_Sites/MapServer/6
 
FPDSI:
https://geodataservices.wdfw.wa.gov/arcgis/rest/services/ApplicationServices/FP_Sites/MapServer
Layer: Natural Barrier - Verified (ID: 5)
 
Here's how R access the verified:
 
library(sf)
 
layer <- "https://geodataservices.wdfw.wa.gov/arcgis/rest/services/ApplicationServices/FP_Sites/MapServer/5"

url <- paste0(

  layer, "/query?where=1%3D1&outFields=*&outSR=4326&f=geojson"

)
 
barriers <- st_read(url, quiet = TRUE)

head(st_drop_geometry(barriers))
Layer: Natural Barrier - Verified (ID: 5)
 
Heres how Python does:
 
import geopandas as gpd
 
layer = "https://geodataservices.wdfw.wa.gov/arcgis/rest/services/ApplicationServices/FP_Sites/MapServer/5"

url = (

    f"{layer}/query?where=1%3D1&outFields=*&outSR=4326&f=geojson"

)
 
barriers = gpd.read_file(url)

print(barriers. Head())
